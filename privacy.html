Privacy policy

This policy describes the current English Video Publisher desktop workflow operated by LimaCxu and this informational website.

Data used by the desktop workflow

When you authorize TikTok, the workflow requests user.info.basic, video.upload, and video.publish. The token response may contain an account identifier, access token, refresh token, scopes, and expiry information. Permission to read basic profile information does not mean the current workflow retrieves every available profile field.

The workflow processes the videos, captions, titles, descriptions, and publishing settings you provide. It stores OAuth credentials and tokens in the local project’s secrets directory, and generated videos and publishing records in local project files. These secrets are not intended for this public website or its repository.

Purpose and sharing

Tokens authenticate authorized API operations. Videos and related metadata are sent to TikTok or YouTube/Google when the desktop workflow requests an upload or publishing operation. These platforms process information under their own policies. The app does not sell personal data or use account tokens for advertising.

Storage and deletion

Local files remain until the operator deletes them. Revoke access using the relevant platform’s connected-app settings, stop scheduled publishing jobs, and delete local token and credential files to disconnect the workflow. Delete local generated files and logs separately. Deleting local files does not delete videos already uploaded; manage those on the platform.

This website

This static website has no app-specific analytics, advertising scripts, sign-in form, or tracking cookies. GitHub Pages hosts it and may process technical request information under GitHub’s privacy statement. This website does not receive the desktop OAuth callback.

Security and contact

Keep local secret files private and secure the device running the workflow. No storage or transmission method is risk-free. Contact the operator through the LimaCxu GitHub profile or open a general support issue in the website repository. Do not post tokens, passwords, or personal account data in public issues.

Changes

Material changes to the workflow’s data practices should be reflected here before the changed functionality is made available.
